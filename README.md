# ПЗ 09. Списки и смысловая контента

[Демонстрация](https://nikolaiethic665.github.io/pz-09/) · [Исходный код](https://github.com/nikolaiethic665/pz-09/tree/kolodei) · [Отчёт PDF](https://nikolaiethic665.github.io/pz-09/materials/report.pdf) · [Pull Request](https://github.com/nikolaiethic665/pz-09/pull/1)

## Цель

Выбирать подходящие списки по смыслу.

## Задание

Разметить данные с помощью разных типов списков.

## Реализация

У регистрации важен порядок, поэтому она оформлена через ol. Список вещей оформлен через ul. Цитата получила отдельный блок и подпись. Дата сохранила видимый текст и машинно-читаемый datetime. Контакт можно открыть в почтовом приложении через mailto.
